## Features

- Advanced citation style templates optimized for rapid formatting and compliance with major academic publishing standards (APA, MLA, Chicago, IEEE, Nature).
- Workflow automation scripts to streamline repetitive batch importing from databases (PubMed, Web of Science, Scopus) and PDF metadata extraction tasks.
- Custom output style configurations and bibliography layout presets for enhanced document consistency and institutional styling.
- Quick-switch macros for seamless navigation between EndNote libraries, Cite While You Write (CWYW) toolbars in Microsoft Word, and group sets.
- Pre-configured library organization profiles with automated duplicate detection, smart groups, and term list management routines.
- Comprehensive documentation and step-by-step setup guides for all included tools, style files, and modules.
- Integration examples and bridge scripts for third-party academic writing applications (e.g., Microsoft Word, LaTeX/BibTeX, Scrivener).
- System resource optimization configs for faster library synchronization and reduced RAM usage during large-scale database operations.
- Ready-to-use collaborative research templates with automated shared library syncing and conflict resolution routines.

## Requirements

- Windows 10/11 (or macOS)
- Installed EndNote (version 20 or 21 recommended)
- Microsoft Word (for CWYW integration)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom citation styles, connection files, and macros directly into your EndNote Styles and Filters folders. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced usage, refer to the `GUIDE.md` file included in the archive.
